# Northline Finance front-end prototype

Static HTML5, CSS3, Bootstrap 5, and vanilla JavaScript prototype for a US/Canada personal and business financing workflow.

## Run

Open `index.html` directly in a browser, or serve this folder with any static web server.

## Important production notes

- This project uses mock application, file-upload, status, and admin data only.
- Do not store identity documents, government identifiers, bank details, or other sensitive information in browser storage or public folders.
- Connect the application to a secure, authenticated backend and storage provider before collecting real applicant information.
- Replace the Northline placeholder brand, rates, terms, legal notices, licensing information, and demo testimonial with approved business content.
